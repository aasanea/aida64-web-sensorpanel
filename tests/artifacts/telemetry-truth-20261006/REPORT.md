# تقرير إصلاح صدق البيانات والبطاقات

تم التطبيق في المشروع الفعلي `D:/Services/aida64_suite/dashboard` بتاريخ 2026-10-06. بقيت الواجهة Vanilla JS / Native Web Components بدون npm أو خطوات بناء. نسخة الملفات للمتصفح: 20261006.10.

## ما تغير

- **Sonar:** قراءة وضع Classic/Streamer من البرنامج أولًا، ثم المسارات الصحيحة للقنوات الست. يعرض Streamer مستوى الاستماع ومستوى البث والكتم لكل مسار بصورة مستقلة. الصفر صحيح ولا يستخدم مستوى Windows بديلًا. فشل الاتصال يمسح القيم. اللوحة المشتركة مستخدمة في أورورا وبقية البطاقات والتصاميم الثلاثة وتفاصيلها.
- **صدق القياس:** مصدر ووحدة ونوع القياس ووقت القراءة وحالته لكل حقل. القيم المفقودة تظهر بشرطة، والنسخة المحفوظة والبيانات القديمة مميزتان. CPU + GPU مجموع محسوب وليس استهلاك الجهاز كله. المضخة لا تستعير مروحة الهيكل. HDR/VRR و1% Low وClearCast والبروفايلات والتوجيه لا تحمل أرقامًا افتراضية.
- **المعالج والرسوميات:** أسماء العتاد من Windows، وتصنيف الأنوية من Windows topology بالأرقام الفعلية بدل افتراض أول ثماني أنوية P. دعم تغير عدد الأنوية وإزالة البيانات المفقودة. FPS من RTSS مستقل عن تردد الشاشة. زمن الإطار مشتق فقط عندما FPS أكبر من صفر، ويُمسح عندما يصبح صفرًا.
- **الذاكرة والتخزين:** توحيد GiB، تمييز ساعة RAM عن معدل النقل MT/s، تعريف وحدات RAM والأقراص الفعلية وربط حرارة NVMe بالقرص الصحيح. مجموع التخزين يبين نطاق C + D، وليس جميع الأقراص. تصحيح دقة الشاشات من Windows عند استخدام DPI scaling.
- **الشبكة:** السرعة والعنوان والمعدل والمجاميع من الواجهة نفسها. المجاميع منذ بدء الخدمة. زمن الاستجابة هو TCP. قوائم البرامج تعرض الاتصالات الحقيقية؛ أزيل استنتاج الشبكة من disk I/O.
- **الطقس والصلاة:** بيانات المصدر المؤرخة بتوقيت الرياض، ومواقيت الأمس واليوم والغد، وفجر الغد بعد العشاء. لا توجد مواقيت ثابتة بديلة. إعادة محاولة تلقائية عند تعذر المصدر، وإظهار حالة الحفظ/القدم.
- **المواعيد والمباريات:** تطبيق أيام التكرار وحساب الوقت المنقضي الصحيح للموعد الجاري. تحديث النصوص مرة في الثانية مع اكتشاف التغيير. مصادر البطولات لها عمر مستقل، وغياب قناة النقل أو الدقيقة المباشرة لا يستبدل بقيم تخمينية.
- **الرسم والوصول:** مسار واحد لتحديث الحالة، ملكية DOM داخل كل مكون، AbortController وإلغاء rAF عند الفصل، وتنعيم يعتمد على زمن الإطار. الوجه الخلفي غير النشط inert وaria-hidden. الثيمات العشرة متاحة، وحفظ العربية RTL والوقت 12 ساعة والتاريخ الأكبر. ضبط المكسر ليظهر جميع المسارات داخل التصاميم الثلاثة، وضبط مؤشر RAM ليبقى داخل البطاقة. تفاصيل وجه الصوت الخلفي قابلة للتمرير داخليًا مع إظهار المسارات أولًا.

## الأداء وحدود التحقق

ملف `frame-results.json` يحتوي عينات rAF الفعلية لكل ثيم: ثانيتان للإحماء ثم ثماني ثوانٍ لكل عينة. `?measure=1` يفعّل التشخيص فقط؛ الواجهة الطبيعية لا تشغله. المئين 95 قرابة 4.3 ms في الثيمات العشرة على المضيف ذي 240 Hz، ولم تُسجل Long Tasks في العينات. أعلى تأخير عابر في OLED بلغ 20.7 ms. هذه نتيجة عينات فعلية، وليست ضمانًا دائمًا لـ60 FPS تحت كل الأحمال، وليست FPS اللعبة.

البيانات غير المقاسة ما زالت «غير متاحة» عمدًا: استهلاك الجهاز كله، مضخة التبريد دون حساس مستقل، HDR/VRR، 1% Low، حالة ClearCast، بروفايلات Sonar وتوجيه الأجهزة. عرض هذه الميزات يتطلب مصدرًا يثبتها؛ لم تُستنتج من اسم الشاشة أو البرنامج.
